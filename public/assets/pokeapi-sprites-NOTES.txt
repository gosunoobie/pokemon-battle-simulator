Unmodified static sprites from PokeAPI/sprites. Pokémon artwork belongs to Nintendo / Game Freak.

The preview roster contains the nine Kanto starters. Each uses dedicated front and back artwork.
Near/player field: back. Far/opponent field: front. Choosing the move user never switches these views.
Alpha bounds are measured; normalized sockets are visually estimated host metadata, never FX.
Back-view mouth/eyes may be obscured. Original Charizard-back and Venusaur-front calibrated sockets are retained.
Original sprite pixel scale at 1000×450: near 265/96, far 235/96. Visible-height floors: 150 near / 125 far.
Width follows the original aspect ratio. No fixed size classes or species-specific enlargement.
